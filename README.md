# 3D FPS Survival - Forest Edition (30s Round)

30초 동안 숲속에서 몰려오는 사람·맹수 적을 피하거나 쏴서 생존하는 의사 3D(Canvas 2D) 1인칭 서바이벌 게임입니다.

* 실행: https://survival-xi-seven.vercel.app/ (또는 `index.html` 을 브라우저로 열기)
* 조작: W/A/S/D 이동, 마우스 시점, 좌클릭 사격, P 일시정지
* 문서: [핵심 규칙 문서](핵심%20규칙%20문서.md) · [검증안내서](검증안내서.md) · [AI 3줄 요약](AI%203줄%20요약.md) · [과제 완주 체크리스트](과제%20완주%20체크리스트.md) · [저장 데이터 목록](저장%20데이터%20목록%20(실제%20코드%20기준).md)
* 저장: 플레이 기록(최근 20회)·누적 통계·설정은 브라우저 LocalStorage에 보관되며, 저장값이 비거나 손상돼도 기본값으로 실행됩니다.

## 확인 방법 (4줄)
1. **위치**: https://survival-xi-seven.vercel.app/ (소스: https://github.com/shk12170-dev/survival)
2. **행동(3단계)**: [게임 시작] → W/A/S/D 이동·좌클릭 발사로 30초 버티기 → [다시 시작]
3. **통과 모습**: 남은 시간 30→0, 성공/실패 배지와 결과 화면, 기록표 1줄 추가, 재시작 시 체력 100·점수 0
4. **안 될 때**: 화면을 한 번 클릭해 마우스 잠금 → 그래도 안 되면 P로 일시정지 후 재개, 기록 이상 시 [기록 초기화]

## 난이도 값 (비교 대상은 1개)
- 비교 값: **적 생성 간격**(쉬움 3.5초 / 보통 2.0초 / 어려움 1.0초). 적 속도·데미지는 모든 난이도에서 동일(고정).
- 핵심 입력: 좌클릭 사격. 클릭 1건 = 총알 1발(쿨다운 없음).
